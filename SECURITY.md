# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |
| < 1.0   | :x:                |

Only the latest stable release receives security updates. Previous versions are no longer maintained.

## Reporting a Vulnerability

We take security vulnerabilities seriously. If you discover a security issue, please report it responsibly by following these guidelines:

### How to Report

1. **Do not open a public issue** for security vulnerabilities
2. Email details to: **security@gamechatpro.com**
3. Include the following information:
   - Description of the vulnerability
   - Steps to reproduce
   - Potential impact
   - Any relevant logs or screenshots

### What to Expect

- **Initial Response**: Within 48 hours of receiving your report
- **Triage**: Within 5 business days, we'll confirm the vulnerability and assign a severity level
- **Fix Timeline**: 
  - Critical: 7 days
  - High: 14 days
  - Medium: 30 days
  - Low: 90 days

### Disclosure Process

1. We'll work with you to understand and verify the issue
2. A fix will be developed and tested privately
3. A security advisory will be published once the fix is available
4. Credit will be given to reporters (unless anonymity is requested)

## Security Best Practices

When using GameChat Pro:

- Keep the application updated to the latest version
- Use strong, unique passwords for your accounts
- Report suspicious activity or potential vulnerabilities immediately
- Do not share sensitive information in public channels

## Third-Party Dependencies

This project uses third-party libraries. Security vulnerabilities in dependencies are monitored and updated according to the timelines above.

Thank you for helping keep GameChat Pro secure.
